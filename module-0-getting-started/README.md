# Module 0 · Getting Started & Your PDI

**Estimated time:** ~55 min  ·  **Topics:** 4

Understand what a ServiceNow developer does, how this course works, and — most importantly — get a working, fully configured Personal Developer Instance **before you write a single line of code**.

## Learning objectives

By the end of this module, you will be able to:

- Describe the ServiceNow developer role and the skills this course builds
- Create your own free Personal Developer Instance (PDI) and log into it
- Wake, reset, and export a PDI so you never lose your work
- Configure the instance for development: session debugging, script logs, and Scripts - Background
- Create a scoped lab application and verify the environment with a working script

## Prerequisites

None. This is the starting point — no prior ServiceNow experience required.

## Knowledge check

Before moving on, make sure you can answer these:

- What is a PDI, and why does this course use one instead of a shared training instance?
- What happens to a PDI after ~10 days of inactivity, and how do you recover it?
- Where do you run ad-hoc server-side scripts, and where does `gs.info()` output appear?
- Why build in a scoped application rather than in Global?
- How would you move your lab work into a brand-new PDI if this one were reclaimed?
