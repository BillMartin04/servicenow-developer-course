# How to Use This Course

This page tells you exactly how to work through the material so you learn fast and do not get lost.

## The rule that matters most

{% hint style="warning" %}
**Go in order, and do not write code until Module 0 is finished.** Modules build strictly on each other. The single most common way people stall is skipping the instance setup and then having nowhere to practise.
{% endhint %}

## What you need before you start

| Requirement | Why | Where |
| --- | --- | --- |
| A free PDI | Every exercise runs in your own ServiceNow instance | [Create your PDI](module-0-getting-started/02-create-your-pdi.md) |
| A configured PDI | Debugging, logs, and a scoped lab app you build in | [Configure your PDI](module-0-getting-started/03-configure-your-pdi.md) |
| ~6 hrs + project time | To complete all modules and the final exercise | [Syllabus](syllabus.md) |
| A notes file | Knowledge-check answers and your project design | Any tool you like |

## How each page is laid out

Every topic page follows the same shape, so you always know where you are:

1. **Title and module breadcrumb** — where this topic sits in the course.
2. **Estimated time**.
3. **What you'll learn** — the objective for this single topic.
4. **Watch** — the YouTube video, embedded directly in the page.
5. **Overview** — the topic in plain language.
6. **Key concepts** — the ideas to internalise.
7. **Hands-on** — a checklist you complete in your PDI.
8. **Resources** — official docs and references.
9. **Navigation** — previous and next topic links at the bottom.

{% hint style="info" %}
**One video, one page.** Each video in the [playlist](https://www.youtube.com/playlist?list=PLWMzEPW90q1Z9-po9BsvC_rHDf5mtubdg) is its own topic page, embedded so you can watch it here while you read and build. You never need to leave the page to follow along.
{% endhint %}

## The learning loop

Repeat this for every topic:

1. **Read the objective** — know what you are about to be able to do.
2. **Watch the embedded video** — pause it as often as you need.
3. **Read the key concepts** — this is the part you should be able to explain out loud.
4. **Do the hands-on in your PDI** — this is where the learning actually happens.
5. **Move to the next topic** using the link at the bottom of the page.

At the end of each module, answer the **knowledge check** from memory. If you cannot, re-watch that topic before moving on.

{% hint style="success" %}
Watching alone will not make you a developer. Building will. If you only have limited time, cut the note-taking, not the hands-on.
{% endhint %}

## If you are already experienced

- **Admin moving into development:** skim Module 1, start properly at Module 2, and do not skip Module 5.
- **Developer from another stack:** read Module 1's client-vs-server topic carefully, then go straight to Modules 3–6.
- **Experienced ServiceNow dev:** go to Module 5, then Module 6, then the [final exercise](module-7-capstone/00-final-exercise.md) and score yourself on the [rubric](module-7-capstone/01-scoring-rubric.md).

In all cases, still read each module's knowledge check to confirm you have no gaps.
