# Course Objectives

This page states plainly what this course is for, who it is for, and what you will be able to do when you finish. Read it before the [Syllabus](syllabus.md) so the curriculum makes sense.

## Course goal

> Build **ServiceNow developers from beginner to expert** — developers who write clean, secure, well-architected code, are ready to work alongside AI, and can grow into the role of **ServiceNow Software Architect**.

## Terminal objectives

When you finish this course, you will be able to:

1. **Set up and operate your own development environment** — provision, configure, wake, and reset a free Personal Developer Instance (PDI), and work inside a dedicated scoped application.
2. **Write platform-safe JavaScript** and explain precisely where any given script executes and why that matters.
3. **Build client-side behaviour** with Client Scripts, UI Policies, Catalog Client Scripts, and Catalog UI Policies — without hurting form performance.
4. **Manipulate data on the server** using GlideSystem, Business Rules (all timings), and GlideRecord for full CRUD and querying.
5. **Package logic for reuse** in Script Includes, extend objects correctly, and bridge client to server with GlideAjax.
6. **Apply professional design patterns** — object-oriented principles, dependency injection, queueing and event-driven design, and a service-bus integration layer.
7. **Integrate and harden** — call external systems over REST, apply secure coding practices, call Script Includes from Flow Designer, and implement global error handling.
8. **Deliver and defend a production-quality application** — build the [final exercise](module-7-capstone/00-final-exercise.md), score it against the [rubric](module-7-capstone/01-scoring-rubric.md), and explain your architectural decisions.
9. **Plan your progression** to AI-ready architect using the [architect roadmap](module-7-capstone/03-architect-roadmap.md) and [certification path](module-7-capstone/04-certification-and-career.md).

## What "AI-ready" means here

An AI-ready developer does not just prompt a model. They build platforms that AI can safely operate on:

- **Layered code** — logic lives in Script Includes with clear boundaries, so a change is localised and reviewable.
- **Injected dependencies** — behaviour can be substituted and tested, so AI-generated changes can be verified.
- **Consistent error handling** — failures are observable rather than silent.
- **Secure by default** — server-side enforcement, so generated client code cannot be trusted into a vulnerability.

These are taught throughout Modules 5 and 6 and assessed in the [rubric](module-7-capstone/01-scoring-rubric.md).

## Prerequisites

- A free [ServiceNow Personal Developer Instance](https://developer.servicenow.com) — you create it in [Module 0](module-0-getting-started/02-create-your-pdi.md).
- A browser and a place to take notes.
- Willingness to type the code yourself. No prior ServiceNow experience is required; JavaScript is taught from the ground up in Module 1.
